# 武印视界 (Wuyin World) 全模块设计文档

**日期**: 2026-04-20
**状态**: 已通过 (待实施)

## 1. 项目概述
构建一个高端、沉浸式的武印视界官方网站，涵盖 5 大核心模块，采用“东方武道 + 赛博科技”的视觉风格。

## 2. 视觉与技术方向
- **视觉风格**: 黑红金主色调，水墨动效结合机甲精密感。
- **3D 地图方案**: 采用预渲染高清 3D 序列帧动画，结合 SVG 坐标热点实现交互。
- **技术栈**: React 19, Tailwind CSS v4, Framer Motion, React Router 7。

---

## 3. 模块详细设计

### 模块一：首页 —— 引力核
- **Hero 区**: 全屏自动播放视频背景，动态主副标题，提供“预约观赛”与“成为伙伴”双入口。
- **武印宣言**: 采用渐现动画 + 水墨特效展示品牌核心价值观。
- **三大价值入口**: 文化/科技/金融卡片式设计，悬停展开详情。
- **六大生态矩阵**: 六边形网格布局，点击链接至对应业务模块。
- **最新动态**: 时间轴滚动展示赛事及 NFT 动态。
- **武印之问**: 轮播切换武者剪影，引发用户思考。
- **[补充]**: 增加 2026 杭州首秀实时倒计时；导航栏采用磨砂玻璃效果（Glassmorphism）。

### 模块二：武印宇宙 —— 文化叙事
- **宇宙地图**: 序列帧 3D 地图，SVG 热点点击展开区域故事线。
- **哲学根基**: “止·戈·印”三感解码，配合书法动画与[补充]语音导览。
- **人物谱系**: 卡牌式展示宗师、武者与守护灵，支持收藏至“虚拟护照”。
- **非遗融合**: 图文 + 纪录片片段展示传统工艺。
- **薪火相传**: 视频 + 深度访谈，探讨武术传承。

### 模块三：武印视界 —— 赛事盛典
- **赛事总览**: 2026 杭州首秀详情，集成[补充]3D 场馆视角预览。
- **仪式感剧场**: 流程演示视频，沉浸式展示封印仪式。
- **武者阵容**: 选手档案 + 战绩 + NFT 数字勋章展示。
- **机甲拳王**: 预告视频 + 技术解读，展示人机对抗亮点。
- **非遗走秀**: 国潮战袍图集 + 设计师访谈。
- **往期回顾**: 短视频集锦展示赛事高光。

### 模块四：武印阁 —— 生态体系
- **六位一体导图**: 交互式 SVG，动态展示六大公司联动逻辑。
- **业务子模块**: 
    - IP 运营: 授权案例与[补充]资源下载中心。
    - 赛事管理: 赛事日历与俱乐部列表。
    - 数字科技: NFT 浏览器与[补充]链上实时看板。
    - 标准认证: 查询入口与证书验真动画。
    - 传媒生态: 视频内容库与内置播放器。
    - 文旅旗舰: 线下场地预约。

### 模块五：合作入口 —— B 端通道
- **分层触达**: 针对品牌、赛事、俱乐部、政府、投资、媒体设置独立入口。
- **核心内容**: 权益包预览、加盟流程、商业计划书下载。
- **合作申请表**: 全类型集成表单，后端自动分流。
- **[补充]**: 增加合作伙伴 Logo 墙与分阶段合作进度示意图。

## 4. 数据流与状态管理
- **i18n**: 全局支持中英双语，文案统一由翻译文件管理。
- **路由**: 使用 React Router 7，支持锚点平滑滚动。
- **动画**: 使用 Framer Motion 处理页面切换与滚动揭示动效。
